# Ավանդական և մեքենայական ուսուցման մոդելների համեմատություն բանկային խարդախ գործարքների հայտնաբերման խնդրում

Մագիստրոսական թեզի գործնական մասի (Գլուխ 3) կոդը։
Թեմա՝ «Ավանդական և առաջադեմ մեքենայական ուսուցման մոդելների և ալգորիթմների կիրառությունները ֆինանսական որոշումների կայացման համատեքստում»։

*Comparison of traditional (rule-based system, logistic regression) and machine learning models
(decision tree, random forest, XGBoost, MLP neural network, Isolation Forest, hybrid) for card-fraud detection
on a synthetic bank transaction dataset.*

## Կառուցվածք
```
src/data_generator.py   – սինթետիկ գործարքների գեներատոր (300 000 գործարք, ~0.6% խարդախ)
src/run_experiment.py   – մոդելների ուսուցում, գնահատում, աղյուսակներ և գրաֆիկներ
results/metrics.csv     – թեստային բազմության չափանիշները
results/figures/        – ROC/PR կորեր, հատկանիշների կարևորություն և այլն
```

## Գործարկում
```bash
pip install -r requirements.txt
cd fraud-ml-thesis
python src/run_experiment.py
```
Արդյունքները վերարտադրելի են (`seed=42`)։

## Տվյալների մասին
Տվյալները **սինթետիկ** են և չեն պարունակում իրական հաճախորդների տեղեկություններ։ Գեներատորը մոդելավորում է
իրական քարտային գործարքների հիմնական հատկությունները՝ դասերի խիստ անհավասարակշռվածություն, հատկանիշների
ոչ գծային փոխազդեցություններ, աղմուկ և ժամանակային կառուցվածք։ Ուսուցման/վալիդացիայի/թեստի բաժանումը
կատարվում է ըստ ժամանակի (out-of-time)՝ 0–119, 120–139 և 140–179 օրեր։

## Մոդելներ
| Խումբ | Մոդել |
|---|---|
| Ավանդական | Կանոնային (rule-based) համակարգ, լոգիստիկ ռեգրեսիա |
| ML (վերահսկվող) | Որոշումների ծառ, պատահական անտառ, XGBoost, նեյրոնային ցանց (MLP) |
| ML (առանց վերահսկման) | Isolation Forest |
| Ինտեգրված | Հիբրիդ՝ կանոնային ազդանշաններ + XGBoost (մետա-լոգիստիկ ռեգրեսիա) |

Գնահատման չափանիշներ՝ ROC-AUC, PR-AUC, Precision, Recall, F1, Recall@1%, ֆինանսական ծախս (բաց թողնված
խարդախության գումար + ստուգման ծախս՝ 5 USD մեկ ահազանգի համար)։
